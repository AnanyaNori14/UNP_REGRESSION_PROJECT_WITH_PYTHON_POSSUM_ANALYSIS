# UNP_REGRESSION_PROJECT_WITH_PYTHON_POSSUM_ANALYSIS

This project presents a comprehensive classification analysis of a customer churn dataset to examine the factors influencing customer attrition. The study involved systematic data preprocessing, including column standardization, categorical encoding, feature scaling, and data splitting to ensure analytical consistency. Exploratory Data Analysis (EDA) was conducted to visualize data distributions, identify patterns, and understand relationships between customer demographics, service usage, and churn behavior. Multiple machine learning models—Logistic Regression, Decision Tree, and Random Forest—were developed to predict customer churn based on key usage and subscription attributes. Model performance was evaluated using accuracy metrics across different train–test splits. Among the tested models, Random Forest achieved the highest predictive accuracy, effectively capturing complex non-linear relationships. The findings highlight the multifactor nature of churn and demonstrate the role of machine learning in customer retention analysis.
